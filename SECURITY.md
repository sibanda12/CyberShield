
# Security Policy

## CyberShield – Password Security Auditor

CyberShield is an educational cybersecurity project developed
to demonstrate password security assessment, secure coding
principles, and basic authentication security concepts.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in CyberShield,
please report it responsibly.

When reporting an issue, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Suggested remediation, if available.

Please avoid publishing sensitive exploit details
before the issue has been investigated.

## Security Practices

CyberShield follows these basic security principles:

1. No plaintext password storage.
2. No external transmission of submitted passwords.
3. No unnecessary collection of user information.
4. Input validation and error handling.
5. Continuous testing and code improvements.

## Responsible Use

CyberShield is intended for educational and authorized
security assessment purposes.

Users should only test passwords they own or have
explicit permission to assess.

## Disclaimer

CyberShield is an educational prototype and is not a
replacement for professional password security auditing
or enterprise authentication security solutions.
